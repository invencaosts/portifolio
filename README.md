- React
- TailwindCSS

## 📖 Projeto

O **invencaodev** reúne minha trajetória como Desenvolvedor Full Stack: experiências em sistemas para saúde pública, gestão empresarial e geodados, projetos em destaque, competências, formação acadêmica e estudos em cibersegurança. Tema claro e escuro, responsivo em dispositivos móveis e desktop, com foco em acessibilidade (contraste WCAG AA).

Os repositórios públicos do GitHub são listados automaticamente via GitHub API. A aplicação Next.js fica na pasta [`invencaodev`](./invencaodev).
